ENROLLMENT FORM - DATA FLOW GUIDE
==================================

WHEN YOU SUBMIT THE ENROLLMENT FORM:
====================================

STEP 1: Form Submission
-----------------------
Form: EnrollForm.html
Action: Submits to → enroll.php
Method: POST (with file uploads)

STEP 2: Data Sent to PHP
------------------------
File: enroll.php
Receives these fields:
✓ fullName
✓ fatherName  
✓ email
✓ phone
✓ gender
✓ courseInterest
✓ studyMode
✓ qualificationFile (uploaded file)
✓ passportPhoto (uploaded file)
✓ cnic (uploaded file)
✓ previousExperience
✓ reasonForJoining

STEP 3: File Storage
--------------------
Files are saved to: uploads/ folder
With names like:
- 1710234567_qualification_filename.pdf
- 1710234567_photo_filename.jpg
- 1710234567_cnic_filename.jpg

STEP 4: Database Connection
---------------------------
Database: programmerslab_db
Table: enroll
Host: localhost
User: root
Password: (empty)

STEP 5: Data Insertion
----------------------
SQL Query:
INSERT INTO enroll (
    full_name, 
    father_name, 
    email, 
    phone, 
    gender, 
    course_interest, 
    study_mode, 
    qualification_file, 
    passport_photo, 
    cnic_file, 
    previous_experience, 
    reason_for_joining
) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)

STEP 6: Database Storage
------------------------
Your data is stored in:
Database: programmerslab_db
Table: enroll

Columns filled:
- id (auto-generated)
- full_name (your name)
- father_name (father's name)
- email (your email)
- phone (your phone)
- gender (male/female/other)
- course_interest (selected course)
- study_mode (online/onsite)
- qualification_file (filename only)
- passport_photo (filename only)
- cnic_file (filename only)
- previous_experience (optional text)
- reason_for_joining (optional text)
- status (automatically set to "pending")
- created_at (current timestamp)

STEP 7: Response
----------------
Success: "Enrollment submitted successfully! We will contact you soon."
Error: Shows specific error message

HOW TO CHECK IF DATA WAS SAVED:
===============================

Method 1: phpMyAdmin
--------------------
1. Open: http://localhost/phpmyadmin
2. Click: programmerslab_db (database)
3. Click: enroll (table)
4. Click: Browse
5. See your enrollment data

Method 2: SQL Query
-------------------
SELECT * FROM enroll ORDER BY created_at DESC;

COMPLETE DATA PATH:
==================

EnrollForm.html 
    ↓ (AJAX POST)
enroll.php 
    ↓ (validates data)
uploads/ folder 
    ↓ (stores files)
programmerslab_db database 
    ↓ (stores form data)
enroll table
    ↓ (success response)
Back to form (shows success message)

FILES LOCATION:
===============
- Form data → Database: programmerslab_db.enroll
- Uploaded files → Folder: uploads/
- Form page → EnrollForm.html
- Processing script → enroll.php
